
# Merhaba, Ben Serkan! 👋

**Frontend Developer | UI/UX Designer | Content Creator**

Kullanıcı deneyimini merkeze alan, **Soft UI**, **Glassmorphism** ve **Bento Grid** gibi modern tasarım dillerini kullanarak etkileşimli web projeleri geliştiriyorum. İngiltere merkezli girişimim üzerinden dijital çözümler üretiyor, aynı zamanda yayın platformlarında içerik üreterek topluluklarla etkileşimde kalıyorum.

### 🚀 Neler Yapıyorum?
- 💻 Modern ve ölçeklenebilir frontend mimarileri kuruyorum (özellikle **React.js** ile).
- 🎨 Kullanıcı arayüzlerini sadece kodlamıyor, baştan sona tasarlıyorum.
- 🍔 İnteraktif ve karekod destekli restoran sipariş sistemleri (Waffle Shop UI vb.) geliştiriyorum.
- 🏋️‍♂️ Özel fiyatlandırma algoritmalarına sahip, "old school" estetiği ve **Motion UI** ile harmanlanmış fitness platformları tasarlıyorum.
- 📦 Birden fazla web projesini tek bir React mimarisi altında birleştirerek performans optimizasyonları yapıyorum.
